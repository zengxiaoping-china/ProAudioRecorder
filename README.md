# ProAudioRecorder

## 项目介绍

ProAudioRecorder 是一个功能强大的音频录制和播放工具，支持实时波形显示、音量监控、音频文件管理等功能。

## 功能特性

### 录音功能
- 支持选择不同的录音设备
- 实时波形显示
- 实时音量监控
- 录音暂停/继续
- 录音时长显示

### 播放功能
- 支持播放录制的音频文件
- 播放进度控制
- 音量调节和静音功能
- 播放波形显示
- 播放暂停/继续

### 文件管理
- 自动列出录制的音频文件
- 文件删除功能
- 文件时长显示

## 技术栈

- C#
- .NET Framework
- NAudio 库（音频处理）
- Windows Forms（UI）

## 安装说明

1. 克隆或下载项目到本地
2. 使用 Visual Studio 打开项目文件
3. 还原 NuGet 包（NAudio 库）
4. 编译并运行项目

## 使用方法

### 录音
1. 选择录音设备
2. 点击 "开始录音" 按钮开始录音
3. 点击 "暂停录音" 按钮暂停录音
4. 点击 "停止录音" 按钮停止录音

### 播放
1. 在文件列表中选择要播放的音频文件
2. 点击 "播放" 按钮开始播放
3. 点击 "暂停播放" 按钮暂停播放
4. 点击 "停止播放" 按钮停止播放

### 文件管理
- 双击文件列表中的文件直接播放
- 选中文件后按 Delete 键删除文件
- 点击 "删除" 按钮删除选中的文件

## 注意事项

- 录音文件默认保存在 `Recordings` 文件夹中
- 播放和录音不能同时进行
- 滚动文件列表时可能会暂时影响波形显示的流畅性
